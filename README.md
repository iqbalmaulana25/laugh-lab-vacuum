`main.ts` (Node 22, no dependencies) writes one funny line — at most 200
characters — answering the prompt (the excuse a robot vacuum gives after
eating a sock), to `/output/entry.txt`. The defence: camouflage.

Run it with:

```sh
node main.ts
```
